# ▶ Running the Programs

Clone the repository

```bash
git clone https://github.com/eritz18/Lagne-Repo.git
```

Switch to the Python branch

```bash
git checkout py
```

Go to the Python folder

```bash
cd py
```

Run any program

```bash
python filename.py
```

Example

```bash
python barangay_visitor_log.py
```

or

```bash
python main.py
```
