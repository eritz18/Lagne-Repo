# ▶ Running the Program

Clone the repository

```bash
git clone https://github.com/eritz18/Lagne-Repo.git
```

Switch to the main branch

```bash
git checkout main
```

Compile the C++ program

```bash
g++ self.cpp -o self
```

Run the program

```bash
./self
```

For Windows Command Prompt or PowerShell

```bash
self.exe
```
