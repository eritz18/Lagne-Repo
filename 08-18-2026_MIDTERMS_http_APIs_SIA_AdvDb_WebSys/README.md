# 📌 About This Repository

**HTTP Status for Dogs** is a simple and interactive web application built using **Node.js and Express.js**.

The project allows users to enter an **HTTP status code**, such as `200`, `404`, or `500`, and receive the corresponding dog image from the **HTTP Dog API/service**.

Instead of directly requesting the external service from the browser, the application uses an **Express.js backend route** to process and validate the status code before returning the appropriate dog image URL to the frontend.

The project was created as a simple demonstration of how a **Node.js HTTP application can make use of a free external API/service**.

The website allows users to:

* 🐶 Enter an HTTP status code.
* 🔎 Search for the corresponding HTTP status dog.
* 🖼️ Display the dog associated with the selected status code.
* ⚠️ Validate invalid or missing status codes.
* 🔄 Communicate between the frontend and Express.js backend.
* 🌐 Use an external HTTP Dog service.
* 📱 Use a responsive and mobile-friendly interface.
* 🖤 Enjoy a simple black-and-white paper-inspired design.
